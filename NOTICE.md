# Notice and attribution

## Inspiration

This repository is an independent, original reimplementation of the **skill set** covered by
the IBM Data Science Professional Certificate. The certificate's syllabus was used only as a
map of *which topics* to practice; every notebook, script, explanation, and diagram here was
written from scratch by the repository owner, on different datasets, in a different order and
voice. No course material, lab file, assignment prompt, or code from the certificate is
reproduced.

This project is **not affiliated with, sponsored by, or endorsed by IBM** or any other
organisation. "IBM" and "IBM Data Science Professional Certificate" are referenced solely to
acknowledge the origin of the skill set as inspiration.

The certificate course codes, lab filenames, and assignment text do **not** appear anywhere in
this repository.

## Datasets

No dataset ships with this repository. `scripts/download_data.py` fetches each dataset from its
publisher and caches it under `data/raw/` (git-ignored). Per-dataset source, license, and
citation are recorded in [`docs/datasets.md`](docs/datasets.md). Summary:

| Dataset | Publisher | License |
|---|---|---|
| Palmer Penguins | Allison Horst et al. (palmerpenguins) | CC0 1.0 |
| books.toscrape.com | Zyte / scraping sandbox | Public practice sandbox |
| OpenFlights | OpenFlights.org | ODbL 1.0 |
| California Housing | StatLib / scikit-learn | Public (BSD-compatible) |
| Gapminder | Gapminder Foundation (via plotly) | CC BY 4.0 |
| USGS earthquakes | U.S. Geological Survey | Public domain |
| Adult Income | UCI ML Repository | CC BY 4.0 |
| Wine Quality | UCI ML Repository | CC BY 4.0 |
| Wholesale customers | UCI ML Repository | CC BY 4.0 |
| scikit-learn built-ins | scikit-learn developers | BSD 3-Clause |
